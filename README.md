# ABC 악보 스튜디오

ComfyUI 안에서 **노래 샘플의 보컬 멜로디를 ABC 악보로 추출**하고, 피아노롤에서 듣고 고친다.

YuE2 · Generate Song 같은 노드에는 ABC 악보를 받는 `abc` 텍스트 칸이 있지만,
ABC는 사람이 손으로 쓰기 어려운 표기법이라 사실상 비워 두게 된다.
이 확장은 `abc` 라는 이름의 텍스트 위젯을 가진 **어떤 노드에나** "🎼 악보 스튜디오 열기"
버튼을 붙인다. 누르면 편집기가 뜨고, 지금 칸에 있던 악보를 읽어 들인 뒤
편집 결과를 그대로 그 칸에 되돌려 준다. 특정 노드 이름을 박아두지 않아서
YuE2가 노드 이름을 바꿔도 계속 붙는다.

## 기능

- 한글 도레미가 적힌 건반, 그리기 · 선택 · 지우개 도구
- 곡 전체 미니맵, 가로세로 동시 확대
- 코드 반주 재생, 건반 클릭 미리듣기
- 노래 샘플: 보컬 분리 → 멜로디·템포 추정 → 원본/보컬/멜로디 비교 → 악보에 반영
- 마이크 녹음: 인스 멜로디 / 보컬 멜로디를 직접 선택해 각각의 줄에 넣기
- 단선율 전용

악보 편집과 마이크 허밍은 브라우저에서 동작한다. 노래 파일 분석에는 아래 오디오 패키지가 필요하다. 편집기는 ComfyUI가 제공하는 주소에서 연다.

## 노드

| 노드 | 하는 일 |
|---|---|
| **ABC 악보 입력** | 피아노롤로 그린 멜로디를 ABC 악보 텍스트(STRING)로 내보낸다. 악보를 따로 보관·재사용할 때 쓴다 |
| **ABC 악보 정보** | ABC 악보에서 조(key) · 박자(meter) · 템포(bpm) · 마디 수(bars)를 읽는다 |

버튼 자체는 두 노드가 없어도 `abc` 위젯을 가진 노드라면 어디에나 붙으므로,
YuE2 생성 노드에 바로 그려 넣어도 된다.

```
[ABC 악보 입력] --abc(STRING)--> [YuE2 · Generate Song]
```

## 설치

ComfyUI의 `custom_nodes` 폴더에서:

```bash
git clone https://github.com/nicekriss/toobusy-abc-studio.git
```

ComfyUI가 사용하는 Python 환경에서 오디오 패키지를 설치한다. ComfyUI-Manager 설치는 보통 `requirements.txt`도 처리한다. 수동 설치라면:

```bash
python -m pip install -r custom_nodes/toobusy-abc-studio/requirements.txt
```

여기서 `python`은 **ComfyUI 실행에 쓰는 Python**이어야 한다. ComfyUI에 포함된 Torch/torchaudio는 교체하지 않는다. 업데이트 전 열린 악보를 적용하거나 저장한 뒤 ComfyUI를 재시작하고 스튜디오를 다시 연다.

## 허밍·가사 노래를 따로 녹음하기

1. **마이크로 멜로디 넣기**를 열고 **인스 멜로디** 또는 **보컬 멜로디**를 선택한다. 기본은 인스 멜로디다.
2. 표시된 넣을 줄을 확인하고 **녹음 시작**을 누른다. 준비 박자가 끝나면 한 음씩 부른다. 마이크 권한이 필요하다.
3. **녹음 중지**를 누르면 녹음 시작 때의 재생 위치부터 선택한 줄에 넣는다. 한 번에 최대 90초다. 없는 성부는 음이 검출되었을 때 생성한다.
4. 다른 종류를 선택하고 다시 녹음하면 별도 성부에 들어간다. 기존 음은 유지하고 **되돌리기**로 한 번의 녹음과 새 성부 생성을 함께 취소한다.

허밍과 가사를 음색으로 자동 분류하지 않는다. 가사로 부른 음도 선택에 따라 인스나 보컬에 넣을 수 있으며, 가사 글자를 받아쓰는 기능은 아니다. ABC에서는 `V:Ins` / `V:Vocal`로 구분한다. 기존 표준 성부 ID 또는 `Ins Melody` / `Vocal Melody` 이름을 찾아 재사용하고, 이름이 다른 임의의 성부는 덮어쓰지 않는다.

녹음 중 탭이나 재생 위치가 바뀌어도 넣을 곳은 유지된다. 악보를 새로 불러오거나 조·박자 설정이 바뀌면 잘못된 위치에 넣지 않고 다시 녹음하도록 안내한다. **닫기**는 진행 중 녹음/분석을 취소한다. 조·박자 보정은 기본으로 꺼져 있다. 마이크는 한 번에 한 선율을 부르는 용도이며 반주가 섞인 파일에는 아래 노래 샘플 분석을 사용한다.

## 노래 샘플로 악보 만들기

1. **노래에서 악보 만들기**를 누르고 파일을 고른다. MP3/WAV/FLAC 등 브라우저에서 읽을 수 있는 형식을 지원한다.
2. 보컬이 뚜렷한 **10~30초 구간**을 선택한다. 기본은 처음 30초, 한 번에 최대 90초다. 파일 전체 길이가 더 길어도 구간을 골라 분석할 수 있다.
3. 반주가 있으면 **반주가 있는 노래**, 아카펠라·단선율 파일이면 **목소리·단선율만 있는 파일**을 선택한다.
4. 분석 후 **원본 구간 / 분리한 보컬 / 추출 멜로디**를 각각 듣는다. 추정 BPM은 두 배·절반으로 잡힐 수 있어 직접 수정할 수 있다. 미검출이면 120을 임시값으로 표시한다.
5. **새 악보로 만들기**는 추출한 보컬 한 줄로 바꾸고 기존 코드 반주를 제거한다. **현재 줄에 추가**는 기존 BPM을 유지하며 재생 위치부터 넣는다. 새 악보로 바꾼 뒤에도 되돌리기로 기존 내용을 복원할 수 있다.
6. 피아노롤에서 틀린 음을 고친 뒤 **이 악보 쓰기** 또는 ABC 파일 저장을 누른다.

기본값은 원래 음정과 시간 보존이다. 원곡의 조를 임의로 바꾸지 않는다. **박자에 맞춰 다듬기**를 직접 켠 경우에만 추정한 박 위치와 표시된 BPM의 16분음표 격자로 보정한다. 보정하지 않아도 ABC 시간 단위로 옮길 때 약 1 tick 이내 반올림은 발생한다.

### 분석 방식과 설치 파일

- 보컬 분리: [PyTorch의 HDemucs MUSDB Plus](https://docs.pytorch.org/audio/2.11.0/generated/torchaudio.pipelines.HDEMUCS_HIGH_MUSDB_PLUS.html).
- 피치: [librosa pYIN](https://librosa.org/doc/0.11.0/generated/librosa.pyin.html), 음 시작과 짧은 무음 구간을 함께 확인한다.
- 모델은 첫 ‘반주가 있는 노래’ 분석 시 공식 PyTorch 주소에서 약 **335 MB**를 받아 `ComfyUI/models/abc_studio/hdemucs_high_trained.pt`에 보관한다. 고정 SHA-256 검증을 통과한 파일만 사용한다.
- 분석은 별도 **CPU 프로세스**에서 한 번에 한 작업만 실행한다. GPU 생성 작업의 모델을 내리지 않는다. PC에 따라 수십 초~수 분이 걸릴 수 있으며 첫 실행은 준비가 더 오래 걸린다.
- 진행 상태와 취소를 지원한다. 서버 실행 중 임시 음원·결과는 30분 후 정리하며, 음원을 외부 분석 서비스로 전송하지 않는다. 다른 PC의 ComfyUI에 접속한 경우에는 그 ComfyUI 서버로 선택 구간이 전송된다.
- 아카펠라 모드는 보컬 분리 모델 다운로드 없이 실행된다. 오디오 패키지가 없어도 기존 피아노롤 편집은 사용할 수 있다.

### 범위와 한계

이 기능은 **보컬 멜로디 한 줄의 자동 채보 초안**이다. 가사·코드·드럼·반주 전체 악보, 합창의 개별 성부를 추출하지 않는다. 반주가 보컬에 남거나 잔향·꾸밈음이 많으면 누락, 옥타브 오류, 잘게 나뉜 음이 생길 수 있다. 추출 후 원본과 비교하고 고쳐서 사용한다. 새 악보는 4/4와 C 조표로 표시하지만 음을 C장조로 이동시키지는 않는다. 원곡의 실제 박자표를 자동 판정하는 기능은 아니다.

기술 검증 범위와 재현 방법은 [오디오 검증 문서](docs/audio-validation.md)를 참고한다.

> ComfyUI-Manager의 "Install via Git URL"로도 설치할 수 있다.
> 기본 설정에서는 그 기능이 꺼져 있으므로(`allow_git_url_install = False`)
> 필요하면 Manager 설정에서 켜거나, 위처럼 직접 `git clone` 하면 된다.

## toobusy 본체와의 관계

원래 [toobusy](https://github.com/nicekriss/toobusy) 노드팩 v0.5.0에 들어 있던
기능을 별도 저장소로 분리한 것이다. 악보 편집기는 성격이 뚜렷이 다른 도구라
본체에 묶어 둘 이유가 없었다.

**toobusy 본체와 이 확장을 같이 설치하면 버튼이 두 번 붙는다.** toobusy는
v0.5.1부터 스튜디오를 빼므로, 그 이전 버전을 쓰는 중이라면 둘 중 하나만 두면 된다.
