빈 곳 클릭은 음 추가 · 끌면 이동 · 지울 땐 지우개 · 오른쪽 버튼 클릭으로도 지워져요

이것만 알면 됩니다

  1. 노란 재생 버튼을 누르면 지금 악보가 그대로 들립니다.
  2. 네모 막대 하나가 음 하나예요. 위로 끌면 높아지고 아래로 끌면 낮아집니다. 왼쪽 건반에 도레미가 적혀 있으니 그걸 보고 맞추면 돼요.
  3. 빈 칸을 클릭하면 새 음이 생기고, 막대 오른쪽 끝을 끌면 길어집니다.
  4. 맨 위 노란 칸은 코드예요. 클릭해서 Am, F 같은 이름을 치면 바뀝니다.
  5. 지울 때는 지우개를 켜고 음 위를 훑으세요. 여러 개를 한 번에 옮기고 싶으면 선택으로 바꿔 빈 곳을 드래그하면 됩니다.

고친 건 자동으로 ABC 악보 텍스트가 됩니다. 직접 글자를 건드릴 일은 없고, 다 만든 뒤 아래 악보 텍스트 버튼을 열어 복사하거나 저장하면 돼요.
